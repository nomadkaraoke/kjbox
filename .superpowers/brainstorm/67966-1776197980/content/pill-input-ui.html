Multi-singer entries show individual name pills. Single-singer entries render as plain text (unchanged). The songs-sung pill shows the minimum count across all singers in the group.

Interaction Details

Creating pills: Tab, comma, or & after typing a name converts it to a pill. Backspace on empty input deletes the last pill.

Removing pills: Click the × on any pill, or Backspace to remove the last one.

Submit: Enter (when song field focused) or click Add. Any text still in the input becomes the final singer (no need to pill it first).

Storage: singers_json = '["Phil","Anya"]', singer = "Phil & Anya"

Single singer shortcut: Just type "Sarah", press Enter — stored as singers_json = '["Sarah"]', singer = "Sarah". No pill step needed.
